🎯 Configuration en 5 étapes

Suit ces étapes dans l'ordre pour activer ton trading personnalisé
1
📋 Récupère ton token unique
Ce token connecte ton EA MT5 à ton compte Kao V2. Ne le partage à personne.

2
📞 Crée ton bot Telegram
  1. Sur Telegram, cherche @BotFather
  2. Tape /newbot
  3. Choisis un nom (ex: "Pierre Kao Bot") et username (doit finir par _bot)
  4. Copie le Bot Token donné par BotFather
  5. Cherche @userinfobot, tape /start · copie ton Chat ID
  6. Ouvre une conversation avec TON bot et tape /start (important !)
✅ Telegram sauvegardé
3
🤖 Télécharge ton EA MT5
Le fichier EA configuré avec ton token unique : ⬇ Télécharger KaoV2_Observer.mq5
Important : ne partage pas ce fichier · il contient ton token unique
4
⚙️ Installe l'EA dans MT5
  1. MT5 → Fichier → Ouvrir le dossier des données
  2. Va dans MQL5/Experts/
  3. Copie le fichier KaoV2_Observer.mq5 ici
  4. Dans MT5, appuie F4 (MetaEditor)
  5. Double-clic sur le fichier · appuie F7 pour compiler
  6. Vérifie : "0 error(s), 0 warning(s)"
  7. Retour MT5 · onglet Outils → Options → Experts
  8. Coche "Allow WebRequest" et ajoute :
    https://...
  9. Glisse-dépose KaoV2_Observer sur ton chart Gold
  10. Active "Allow Algo Trading" · OK
5
✅ Vérification
  • Smiley 🙂 vert en haut à droite du chart MT5
  • Logs onglet "Experts" : === KAO V2 OBSERVER ACTIVE ===
